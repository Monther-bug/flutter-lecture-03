main()The front door. Every Dart program starts here.

voidThis function doesn't give back a value.

Lines 10–12

build(): "what should I show?"

  runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {

      debugShowCheckedModeBanner: false,
      home: Center(
        child: Text('Hello, Flutter!'),
      ),
    );
  }
}

Every widget has a build method. Flutter calls it to ask: "What should I draw?"

@overrideWe write our own version of build.
Widgetbuild must give back a widget.
returnHere is the answer: this widget.
contextWhere the widget sits. Ignore it for now.
Mobile App Development · Lecture 03

Analogy: the build method is the widget's drawing. Flutter asks "draw yourself", and build returns the picture made of other widgets.

Troubleshooting

4 beginner mistakes (everyone makes them!)

Expected to find ';'.A line is missing its ; at the end. Add it.
Undefined class 'StatelessWidget'.The import line is missing at the top.
The method 'text' isn't defined…Dart cares about capitals: write Text, not text.
Expected to find ')'.A bracket is missing. Every ( needs a ), every { needs a }.
Tip: red underline in VS Code = a mistake. Hover over it to read the message. Shift + Alt + F tidies your code.
