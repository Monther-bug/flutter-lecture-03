# Lecture 03 · Mobile App Development with Flutter

Open `index.html` in Chrome or Edge (double-click works, no server needed). Light theme by default; press **T** for dark.

| Key | Action |
|---|---|
| → ↓ Space PageDown | Next slide (presenter clickers work) |
| ← ↑ Shift+Space PageUp | Previous slide |
| Home / End | First / last slide |
| F | Fullscreen |
| N | Speaker notes |
| T | Light / dark theme |

Jump to a slide with `#5` at the end of the URL. Print → Save as PDF gives one slide per page.
